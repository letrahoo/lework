# Lework 产品与交互体验原则（UX Principles）

> **主导原则：复杂应该留给系统，不要留给用户；用户体验至高无上。**
>
> Lework 连接着多台主机、多种网络通道（局域网 / Tailscale / SSH 隧道 / Relay）与多种 AI 编码引擎。一切底层发现、重试、协议协商、安全校验、状态恢复与默认值推断，都必须由系统在后台静默消化，绝不能转化为用户的认知负担、晦涩术语或多余点击。

---

## 一、八条核心体验准则

所有界面设计、文案撰写、交互流转与功能评审均以以下 8 条准则为准绳：

### 1. 系统能判断的，不留给用户（Infer, Don't Ask）
- **平台感知**：系统已知当前是桌面端还是移动端，桌面端绝不提示「扫码配对」，移动端绝不显示「桌面端视图」或「SSH 直连」。
- **输入类型识别**：用户在连接框粘贴 `lework://pair?...` 配对链接时，自动识别为配对模式并隐藏多余的「访问令牌」输入框；接入本地代理地址（如 `:8317`）时自动匹配对应适配器。
- **能力与状态推断**：根据仓库是否为 Git 目录、模型是否支持多档推理等级、当前是否处于活跃会话，由系统直接决定展示内容与默认配置，不要求用户自己理解底层差异。

### 2. 此刻没用的，就不出现（Context-Aware Minimalism）
- **无活跃会话时**：隐藏「会话产物」入口、归档按钮及仅对当前会话生效的 `/artifacts`、`/rename` 命令。
- **非 Git 目录时**：隐藏「版本快照」页签与保存快照按钮，仅给出清晰说明。
- **单选项不展示切换器**：当前模型仅支持 1 档推理等级时，隐藏底部推理切换筹码并在面板中折叠无意义的选择列表；仅 1 个可用引擎时不展示多余筛选器。
- **不重复堆砌信息**：桌面端右侧检查器已有统一顶栏标题时，内部子面板不重复渲染大标题；进阶配置（环境变量名、底层协议接口、手动补充模型列表）默认折叠至「高级选项」。

### 3. 能替人做的，就直接做（Act Automatically When Safe）
- **弹窗即焦点**：打开全局搜索（`⇧⌘F`）、会话内查找（`⌘F`）、模型切换（`⌘K`）、重命名会话 / 主机弹窗时，自动聚焦输入框并支持 `↑↓` / `Enter` 直接完成操作。
- **自动发现就绪节点**：进入「连接其他 Lework Hub 主机」时，若内置 Tailscale 已登录，直接在后台探测可用主机列表，无需用户再手动点一次「搜索并握手」；桌面端同步静默检测剪贴板中的 `lework://pair` 链接并浮出一键配对卡片（移动端不主动读剪贴板，避免触发系统弹窗打扰）。
- **自动兜底与恢复**：取消单条待发队列消息时，保持输入框干净并在顶部提供一键「放回输入框」（绑定原会话，不打断用户当前编辑）；归档会话后提供一键「撤销」；回退快照前自动备份当前改动。

### 4. 同一件事，处处一样（One Concept, One Name, One Pattern）
- **跨入口结构统一**：桌面端左侧栏主机切换、移动端抽屉主机切换、设置页主机列表统一采用「左侧标题 `Lework Hub 主机` + 右侧动作 `＋ 连接其他`」布局；macOS 菜单栏同步使用「连接其他 Lework Hub 主机…」。
- **唯一术语表（全端强制对齐）**：

| 概念 | 规范中文文案 | 禁止混用的旧称 / 黑话 |
| --- | --- | --- |
| 被连接的宿主机 | **Lework Hub 主机**（紧凑处简称 **主机**） | 开发机、电脑主机、节点设备 |
| 宿主机配对命令 | **`lework pair`** | `hub pair`、`node hub` |
| 代码差异与回退 | **代码变更与快照**（紧凑处简称 **变更与快照**） | 检查点快照、Diff 检查器 |
| 会话生成的方案/清单/总结 | **会话产物** | Brain Artifact、结构化产物黑话 |
| 并行派发的子代理 | **子任务** / **多智能体** / **工作流** | 面向用户直接暴露 `SubAgent`、`Swarm` |
| 思考强度调节 | **推理等级**（轻量 / 标准 / 深度 / 超高 / 极限） | 推理深度 |
| 独立 Git Worktree | **独立分支工作区**（简称 **独立分支**） | Worktree、临时隔离目录 |
| 退出当前主机连接 | **断开连接** | 退出登录 |
| Token 计量单位 | **Token** | 混用 `Token` / `tokens` |
| 自建 Tailscale 控制面 | **自建服务器地址（如 Headscale，可选）** | Headscale 控制面地址 |

- **交互一致**：桌面与移动端的 `/` 命令面板、`@` 引用文件弹窗均支持点击触发按钮再次点击收回；复制操作统一在写入成功后给出 1.6 秒「已复制」反馈。

### 5. 按下去有回应，再按能收回（Immediate Feedback & Reversibility）
- **每个点击都有即时视觉反馈**：
  - 刷新会话列表显示旋转/加载反馈，避免点下去毫无动静；
  - 停止生成时立刻进入「正在停止…」防连点；
  - 文件浏览器的目录加载、空目录与读取错误均明确呈现，绝不静默吞错；
  - 所有复制按钮仅在写入剪贴板成功后切换「已复制」状态。
- **每个打开与操作都能顺手收回**：
  - 所有浮层与弹窗统一接入 `ModalEscapeEffect`，桌面端按 `Esc` 严格按后进先出（LIFO）逐层关闭；
  - 从工作台点击「连接其他 Lework Hub 主机」**绝不强行断开当前连接**，顶部提供 **`← 返回「当前主机」`** 且支持 `Esc` 无损秒回；
  - 归档会话立即在底部提示条给出 **`撤销`** 按钮，一键恢复；
  - 侧边栏展开的主机面板在点击其他会话、新建会话或开始搜索时自动收起。

### 6. 不打断人手上的事（Never Interrupt Active Flow）
- **零侵入后台能力**：查看或配对其他主机时保留当前会话、连接与草稿；后台更新检查、重连与增量同步静默完成，不弹出打断式强提醒。
- **尊重输入法与阅读位置**：所有 `Enter` / `Esc` 快捷键必须判断 `composition == null`，绝不截断中文拼音候选；用户上翻阅读历史消息时绝不强拉回底部。
- **非阻塞提示**：轻提示与错误优先就地内联展示并自带可操作按钮（如「重试继续」「撤销」），不滥用模态弹窗阻断主流程。

### 7. 常用的好做，会丢东西的难误碰（Fast Common Paths, Safe Destructive Actions）
- **高频路径最短化**：支持键盘直达（`⌘N` 新建、`⌘K` 切模型并直接输入过滤 + `↑↓`/`Enter` 确认、`⇧⌘F` 全局搜索、`⌘F` 会话内查找、`⌥↑`/`⌥↓` 切会话、`⌘1-9` 速切）；添加模型服务提供一键预设模板。
- **不可逆或清空类操作必须二次确认**：
  - `断开连接`、`移除主机记录`、`移除模型服务`、`清除全部本地凭证`、`退出 Tailscale 账号`、`回退快照` 均须二次确认；
  - 确认弹窗必须说清「会清除什么」与「什么会被安全保留（如主机上的历史会话与项目文件）」。
- **保护用户输入心血**：按会话隔离草稿与待发图片；取消单条排队消息自动回填到空输入框，防止误丢长文本。

### 8. 界面自己说明自己（Self-Explaining UI）
- **人话优先，去底层黑话**：用「正在重新连接主机并同步最新消息…」替代「正在校验权限并续连当前会话上下文…」；用「暂未连上主机，请确认网络正常且主机服务正在运行」替代「唤醒校验未通过」。
- **空状态给出下一步**：空会话列表区分「搜索无结果」「某引擎无历史」「全新用户暂无历史」，直接引导下一步动作；搜索空态不写特定业务的私有示例词。
- **控件自解释**：展开面板具备清晰的区域标题；桌面图标按钮统一配备带快捷键的悬浮说明（`LeworkTooltip`）。

## 二、开发与评审自检清单（PR UX Checklist）

提交任何涉及 UI、文案、错误提示、CLI 输出或状态流转的改动前，对照逐项核查：

- [ ] **判断留给系统了吗？** 有没有让用户手动填系统本来就能推断的字段或平台不匹配的文案？
- [ ] **没用的藏起来了吗？** 当前状态下不可用或无意义的按钮、页签、输入项是否已隐藏或折叠？
- [ ] **能自动做的做了吗？** 弹窗输入框是否自动聚焦、可键盘确认？可自动探测/自动回填的环节是否已替用户完成？
- [ ] **全端术语一致吗？** 是否全部对齐上方唯一术语表（零「开发机」、零 `hub pair`、双端一致）？
- [ ] **点下去有回应、再按能收回吗？** 加载/成功/失败反馈是否完整？`Esc`、返回、撤销是否畅通无损？
- [ ] **会打断用户吗？** 是否保护了输入法组合态、草稿内容、现有连接与阅读位置？
- [ ] **会丢东西的操作有护栏吗？** 清除/移除/退出/回退等操作是否都有清晰的二次确认或撤销机制？
- [ ] **界面自己能说明自己吗？** 新用户不看文档也能看懂每个标题、状态、空态与报错提示吗？
